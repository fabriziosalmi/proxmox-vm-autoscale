# Changelog

::: warning Tags are not in chronological order
`v1.2.0` was published in December 2025 and `v0.1.1` in April 2026 — the two
release lines were never reconciled. Entries below are **chronological**, so
`1.2.0` appears after `0.1.1`. From `1.3.0` onwards the numbering is monotonic
again. Go by [the releases page](https://github.com/fabriziosalmi/proxmox-vm-autoscale/releases)
rather than by the highest number.
:::
